# BuscaInsta

Pesquisa e prova de conceito **local/offline** para validar dados de contato e revisar, com autorização, possíveis correspondências de perfis Instagram.

> Estado inicial: repositório recém-inicializado. A implementação Windows e seus testes serão desenvolvidos em uma branch e revisados por Pull Request. Nenhum cliente ou credencial deve ser incluído neste repositório público.
